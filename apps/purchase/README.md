# 采购台

手工录入、表格导入、原始附件、手机录入、供应商、地址、月度确认和订单日志。图片/PDF/OCR 识别及模块设置、备份、帮助入口已移除。

当前统一文档：[功能架构](../../docs/architecture.md)、[源码开发](../../docs/development.md)、[验收规则](../../docs/verification.md)、[运行维护](../../docs/operations.md)。日常从仓库根目录运行 `npm run dev`，使用隔离测试账本，无需打包。

本模块测试在本目录运行 `npm test`。根源码工作台负责启动及切换；单独运行 `npm start` 默认数据位置可能不同，调试时必须明确指定隔离数据目录。

五个模块、外部 MCP/CLI 和公共备份继续保留；已认证公司成员同权，保留真实身份与请求签名。历史账本、登录资料、附件及报表不清除。历史文档从 Git 或清理前本地备份追溯，运行证据统一写入仓库根目录的 `.codex-artifacts/engineering`。
