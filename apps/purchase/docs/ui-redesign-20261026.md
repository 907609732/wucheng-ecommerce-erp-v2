# 采购台现代工作台视觉改版

> 2026-10-27：按用户最新要求，已撤下本篇的蓝色主题。当前界面恢复原版绿色、白色侧栏、圆角看板和设置卡片；仅保留新增功能。`workbench-theme.css` 和 `surface-theme.css` 不再由页面加载，文件保留作历史参考。新增任务卡片沿用原版绿色。月份快捷切换、移除“手工”平台、任务分派、人员管理和验收流程均保留。当前效果见 [恢复后的采购看板](ui-original/dashboard.png)。下文为历史改版记录。

用户选择：冷灰白底、蓝色强调，接近飞书/Linear。只修改采购台。UI、UX和工具调研分工协作完成。

## 视觉与交互

- 192px侧栏、48px顶栏；全站中文层级、按钮、表单、数据行和弹窗统一。普通页面限宽1640px，订单页使用工作区全宽。
- 主色 #245BDB；底色 #F6F7F9；正文 #1F2329；次文字 #646A73；分隔线 #DEE2E8。
- 去除品牌英文、占位头像、重复口号、页面标题副说明及统计装饰图标。数字保留等宽数字，金额和表格保持可读。
- 看板用连续统计带与分类分项；图表改蓝灰数据色。
- 任务中心保留19项真实任务；进度改紧凑摘要；长说明、历史备注和备用操作按需展开，保留主要执行和结果记录入口。
- 订单页状态标签和显示设置一行，筛选条件另一行；中文平台、状态、口径和排序有明确最小宽度。
- 设置用分组清单；月度确认、日志、表单、辅助核对页面与手机页面共享同一视觉方向。
- 弹窗沿用现有焦点限制与Esc关闭，补回关闭后的触发按钮焦点。无需新增框架或在线字体。

## 实施文件

新增workbench-theme.css作为主页面最后加载的视觉层；surface-theme.css统一独立核对页和手机页。原业务样式保留，便于继续调整和回滚。手机实际服务显式提供surface-theme.css，未改变手机配对或鉴权。

GitHub Skill/MCP筛选见 [工具对比](ui-design-tools.md)。采用frontend-design与fixing-accessibility的适用指导，不为工具迁移React/Tailwind，不新增付费服务、APIKey或MCP配置。

## 第二轮：默认字号与工作区层次

用户反馈上一版字太小、仍缺少飞书工作台的感觉。此次将标准100%下的默认正文改为15px、任务标题16px、表格与输入控件14px、页面标题24px；保留现有字号设置，相对新基础值缩放，不覆盖浏览器偏好。

侧栏调整为224px浅灰底，主工作区为白色，顶栏56px。月份改为灰底轻分段，任务进度压成摘要，去除阶段卡片外框，主要任务操作横向排列。核对口径收为可展开说明，业务内容仍保留。金额和支出统计列加宽以容纳14px标题。

本轮语法检查通过；浏览器读取标准比例下实际字号为正文15px、任务标题16px、数据14px、侧栏15px；1440px桌面和768px窗口无页面横向溢出，月份切换保留19项任务。未重新执行纯业务测试，账务流程不变。
