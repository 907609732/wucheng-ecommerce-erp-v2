# 运费导入入口验收

本变更只收敛销售台前端。后台运费 API、正式记录、附件与审计不删除、不变更；发布由总协调执行。

- 运费面板右上角只有「开始导入运费」动作，不再出现导出运费 Excel、运费录入或第二个 AI 导入按钮。
- 空态指向「开始导入运费」；记录行只能查看，详情无编辑、作废和人工费用输入表单。原金额、凭证和历史附件可读。
- 弹窗初始只选平台。菜鸟云仓显示步骤、只读提示词与完整三文件 Skill、复制与 ZIP 下载；商家寄件/顺丰仅显示待开通，复制和下载不可达。
- 快速点菜鸟再点待开通平台，延迟返回的 Skill 不能覆盖当前状态；读取中关闭弹窗后不得回写隐藏弹窗或新弹窗。
- Skill 读取失败显示可重试入口；剪贴板拒绝时选中完整文本并提示 Ctrl+C。
- 复制和切换平台不提交业务写入请求，不宣称软件执行了导入。
- 390px / 600px / 桌面检查：平台按窄屏单列、按钮可换行、只读文本自然折行、关闭按钮可达、无水平溢出。平台选中态使用 aria-pressed 和绿色主题。

自动验证：`node --test apps/sales/test/freight-import-assistant.test.mjs apps/sales/test/personnel-ui.test.mjs`。
包含异步平台竞争、关闭中止回写、失败重试、复制失败手选以及人员/任务导航回归。浏览器和安装态验收由总协调在整合后执行。
