# 使用指南

[返回项目首页](../README.md) · [数据与备份](DATA.md) · [接口参考](API.md)

## 页面入口

默认打开「任务中心」。老板侧栏依次为「任务中心」「运营总览」「资金对账」「运费」；「设置」固定在左下角。员工侧栏只显示「任务中心」和「运费」，准备资料的入口位于任务步骤中。只有老板存在待确认修改时，侧栏才显示该入口和数量。

| 页面 | 用途 |
| --- | --- |
| 任务中心 | 按当前人员身份显示准备、交接或老板核对任务，保留月份和店铺 |
| 运营总览 | 查看已取得账单的收支趋势与店铺对比；有正式运营报表时展示对应经营指标 |
| 运费 | 记录云仓、商家寄件和顺丰费用，查看趋势、归属、凭证及导出 |
| 资金对账 | 先选店铺，再看这家店本月；全年记录折叠收起，结算与银行到账单独核对 |
| 线下与代发 | 登记销售、退款、收款及应收关联 |
| 店铺与数据 | 查看渠道及数据覆盖；自动采集状态与手工账单导入是不同能力 |
| 账单导入 | 平台专用导入、通用列映射、原件下载及批次历史 |
| 月报确认 | 检查数据缺口，预览并锁定月份，查看历史 |
| 任务与备份 | 月报任务、备份、校验和副本恢复 |

## 每月怎样做

老板可在「设置 → 店铺与数据」点击「删除店铺」，输入完整店铺名称确认。仅没有账单、流水、运费及锁定月历史的空店铺可以删除；已有业务记录的店铺会被服务端阻止删除。删除会保留审计记录。

启动工作台时选择「员工」或「老板」，无需新增第三种人员或注册流程。切换身份会关闭原业务页面，重新进入对应工作区。

| 身份 | 本月负责的工作 |
| --- | --- |
| 员工 | 导入账单、补齐经营和费用资料；准备完成后提交给老板 |
| 老板 | 核对资金、检查月报、确认锁定与最终导出交付 |

员工界面不显示资金核对和月报检查入口，直接打开相应页面或调用接口也会受到权限校验。员工提交后显示「等待老板处理」。提交资料不表示资金已经核对或月报已经确认；资料内容变化后需要重新提交，老板正常核对资金不会把员工提交记录当作新资料变更。

完整月度工作分五阶段，员工任务依次为「导入账单」「补齐记录」两步，老板任务仍为「核对资金」「检查月报」「锁定交付」三步。右侧的大任务卡会说明当前处理哪家店、点击哪个按钮及接下来的三个动作。点击流程节点可以查看该步的处理明细；查看其他步骤后，可用「返回当前任务」回到系统建议项。店铺队列优先展示当前需要处理的一家。

1. 在任务中心选择要处理的月份，从「按店铺导入本月账单」开始，核对导入预览后提交。线下、代发使用「去登记」。
2. 员工补齐经营和单店费用资料，在「店铺与数据」留下整月依据；运费单独登记。资料齐全后提交给老板，页面显示等待老板处理。
3. 老板逐店进入资金对账，核对本月范围、收支分类、原始流水及真实到账，并登记结算与实际收款核对依据。已导入、日期覆盖完整、平台参考相符与人工核对结果分别展示。
4. 检查并生成月报。账单变化后需要重新生成，旧生成记录不代表当前数据完整。
5. 查看月报确认页，确认锁定后导出全部店铺本月 Excel，检查下载文件后交付。锁定可能保留数据缺口，需一并说明。

任务中心不包含登记店铺任务或新增店铺按钮。店铺维护保留在原有「设置 → 店铺与数据」中；未配置店铺时，任务中心只提示联系管理员配置。账单导入、草稿状态与本月导出放在任务流程内；逐笔导出、运费录入等操作保留在对应页面。任务切月、切店及往返明细会保留当前月份和店铺。

## 拼多多官方 ZIP

1. 从官方商家后台导出货款账务明细 ZIP，保留原包。
2. 在「账单导入」选择拼多多入口，指定已核实的店铺。
3. 预览导出时间范围、收入、支出、笔数、重复记录和锁定状态。
4. 校验通过后提交，进入「资金对账」选择店铺与月份；如需跨月查看，展开本店全年记录。
5. 点击月份、金额、笔数或分类进入明细，核对原始文件。

原包应仅含一份受支持格式的 CSV。系统核对文件尾部的官方笔数与金额；解析失败或范围异常时不能直接提交。

**不要只凭订单号、文件名或相同金额判断店铺来源。** 来源不确定时可留在「店铺待确认」，确认后再整批归属。正式汇总排除待归属批次。

相邻文件可能跨自然月，例如一份结束于下月 1 日中午。月表按流水发生时间拆月，并合并同一店铺各文件的声明范围判断覆盖情况。

## 淘宝交易货款 CSV

1. 从官方账单导出单月交易货款 CSV。
2. 保留 `交易货款_YYYYMM_YYYYMM.csv` 文件名，前后月份必须相同。
3. 使用「导入淘宝货款 CSV」，选择真实淘宝店铺。
4. 核对账期、货款收入、退款、新增及重复记录，确认后提交。
5. 在运营总览筛选该店铺，点击金额查看明细。

系统保留账期、主订单、子订单、商品、数量、退款单号、业务流水号、打款渠道及原始字段。长订单号按文本保存。

同一业务流水号可能包含多个子订单；收入和逆向退款也可能分行出现。系统不会只按主订单或业务流水号删除其他业务记录。

此文件采用**账期口径**，不导入为支付日期销售额。导入后标注「待核对」，需要与平台月汇总进一步核对；也不能据此认为平台费用、提现和银行收款已经齐全。

## 通用 CSV / TSV / XLSX

1. 选择店铺、归属月份和文件类型：运营报表或资金流水。
2. 必要时指定 XLSX 工作表和表头行。
3. 映射原件列名，填写来源和指标定义。
4. 检查预览，处理错误与冲突后提交。

日期或区间必须在所选月份内，跨月文件先拆分。运营模板提供支付金额、支付订单数、退款、广告和流量字段；未提供的指标保留空缺。旧 `.xls` 文件需先另存为 `.xlsx`。

单次上传限制为 25 MB。通用表格导入最多 50,000 行；不要通过删除业务行或改变金额来绕过校验。

## 明细筛选与导出

- 支持订单号搜索；淘宝还支持搜索子订单号。
- 可组合日期、收支方向、分类与来源文件；支持排序及每页 50 / 100 笔。
- 上方合计对应**全部筛选结果**，不是当前页。
- 「导出全部筛选结果」导出同一范围；订单号为文本。
- 点击行或「原始信息」查看备注、原件行号并下载原件；淘宝可展开全部原始字段。
- 未取得月份不会自动补零；零值与缺失值含义不同。

## 结算与实际收款

平台结算账单与支付宝、微信、银行卡、PingPong 实际收款分别导入。支持分次、合并和跨币种金额匹配；相同金额仅能作为核对线索，不能自动证明是同笔业务。

提现到自己的账户不产生新销售收入，也不作为经营费用重复扣除。货款入账、买家退款、平台费用和内部转账应保留各自分类。

## 运费看板与录入

左侧进入「运费」，右上角点击「运费录入」。先选费用类型，再填月份或日期、归属和金额，核对下方合计后保存。

| 类型 | 怎么选归属 | 填写内容 |
| --- | --- | --- |
| 云仓发货（默认） | 固定为多店共用 | 快递运费；展开「其他费用」可填打包、耗材、仓储及其他费用 |
| 商家寄件 | 必须选实际店铺 | 店铺商家寄件费用 |
| 顺丰快递 | 指定店铺或多店共用 | 顺丰寄件费用 |

- 默认按月汇总；按日汇总和单笔寄件填写实际费用日期。月账单不会平均分到每天，日看板会提示当月另有月汇总。
- 件数、账单号、运单号、备注和凭证均为选填；其他费用金额大于零时，需要说明用途。
- 凭证支持 PNG/JPG/WebP、PDF、XLS/XLSX、CSV，每笔最多 5 个，单个 25 MB、合计 50 MB。附件仅作为原件保存，不会自动导入金额。
- 「保存并继续」保留类型、期间和归属，清空金额、单号及附件；保存失败会保留输入。关闭未保存表单时可继续填写或放弃。
- 遇到重复或期间重叠提示，先检查已有记录；仅在确认本笔未包含于已有费用时，勾选说明后再保存。
- 看板支持时间、归属及费用类型筛选；点击金额卡片或归属可切换筛选。Excel 导出包含全部筛选结果，不局限于当前页。
- 「查看」可下载凭证、编辑或填写原因作废。作废记录不再计入金额，通过「显示作废记录」仍能查看；移除的凭证在详情的历史附件中保留。
- 共用费用不计入单店；未录入显示“尚未录入”。件数未完整填写时不计算平均运费，录入条数不等于包裹数。
- 运费独立统计，不改变现有运营总览、经营结余或资金对账金额；月份锁定同时保护运费和附件，修订需先明确解锁。

## 线下与供货代发

先登记销售业务编号，再通过该编号关联退款和分次收款。代发表示向客户提供供货及代发服务，登记客户应付供货款与运费；收款不会再次增加销售额。

## 月报与更正

1. 导入并核对各渠道数据，检查缺失月份、原币及汇率来源。
2. 生成月报草稿；有缺口时不能当作完整经营结果。
3. 核对完成后，明确确认锁定月份。
4. 修正错误需要填写解锁月份与原因；旧快照和历史继续保存。

批次撤销保留原件和审计，已存在匹配的记录需要先处理匹配。锁定范围不能直接改流水、归属或匹配。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 与平台金额不同 | 先核对店铺、日期范围、支付 / 账期口径和缺失原件，再核对分类 |
| 账单里没有店铺名 | 导入时指定已核实店铺；导出后按「平台 / 店铺 / 月份」整理原件 |
| 同一订单出现多行 | 可能是不同子单、收入、退款或费用，不应仅凭订单号去重 |
| 提现导致账户净变动很低 | 账户净变动包含资金转移，不是利润；查看提现分类并补齐实际用途记录 |
| 页面提示已过期 | 服务重启会更换会话令牌，刷新页面后重试 |
| 端口被占用 | 使用 Windows 启动脚本，查看输出地址或 `data/server.port` |
| 月报仍是草稿 | 补齐原件、核对数据覆盖；任务不会自动制造缺失指标 |

### 经营结余、提现与利润

运营总览的「已知经营结余」按已取得账单的交易入账、补贴等收入、费用返还，减去退款和平台费用计算。提现及营销/保证金账户划转不参与此计算，未知分类单列待确认。「账单现金净变动」保留全部账户收支，含提现，用于核对流水，不代表利润。

总利润在销售商品成本、快递/顺丰/云仓、工资、税费及其他费用补齐前显示缺失；淘宝目前仅有交易货款账单，其费用和提现不按零处理。提现记录不是银行到账凭据；营销充值不直接等于广告消耗，采购付款不直接等于当期销售成本。
