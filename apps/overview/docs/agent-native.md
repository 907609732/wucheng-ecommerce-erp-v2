# 经营总览 Agent 接口

适配器入口为 `lib/agent-adapter.mjs` 的 `createOverviewAgentAdapter({transport})`。主机传输层注入签名工作台身份、中央复核证明、任务编号和幂等编号；模型输入不能声明身份或审批。独立模块只接受允许列表中的 Agent 路由，原 UI 写接口的限制继续生效。

财务信息、原件、费用和付款操作限老板权限。模板和云仓连接状态可由其他已认证人员读取。付款能力只登记已发生的流水，不执行银行付款。

## 业务覆盖

- 查询：月报、年度/月度看板、账单详情、付款登记、审计、采购/销售来源分类、筛选明细、月报快照。
- 文件：导入模板、月报/运费导出、来源原件、云仓归档文件、已有备份下载。
- 财务复核后执行：新增/更正/作废运费、工资和其他费用；登记/撤销付款；来源分类、覆盖确认、快照留存；原件导入与维护回导；备份恢复到独立副本。
- 云仓：读取连接与下载任务、开始/停止/继续原有下载流程。下载只归档原件，不自动产生费用账单；财务导入另行复核。

所有能力具有中文输入规范，字段、枚举、日期、分金额、分页范围、版本、原件摘要均在服务端校验。列映射通过 `options.mapping` 提供；重新预览后再准备导入。`overview.file-stage` 自动接收任务原件，导入预览、导入及恢复副本可使用 `file:{id}`；文件 ID 绑定当前人员和任务。上传原件支持 CSV/XLSX/ZIP，任务原件上限 25MiB；较大恢复备份可通过有摘要的完整 Base64 传入，恢复上限 100MiB。

## 一致性与回执

准备时使用真实领域校验；事务回滚保证预览不记账。服务端保存私有草稿，公开结果仅含不透明的 preparationId。中央证明绑定人员、任务、能力、结果版本、账本实例、业务与采购/销售来源修订、差异摘要和幂等编号。复核后来源变化会拒绝提交。适配器优先使用主机 transport.binding；主机必须返回 `/agent/binding` 的完整修订（包括采购和销售来源摘要），不能只返回经营总览本地修订计数。

提交前生成完整备份，正式账本与持久回执同一事务提交；重试相同幂等编号只返回原回执。提交后回读领域记录及原件摘要，回读失败则回滚账本事务。回执顶层状态是 completed、pending 或 unknown，后两者不得当作业务完成。备份恢复始终创建独立目录，不替换正在使用的数据库。上传不接受任意本机路径，原件必须提供文件名、完整字节及匹配的 SHA256。

## 验证边界

测试使用临时真实 SQLite、实际 CSV/XLSX/ZIP 文件、签名 HTTP 请求和模拟云仓浏览器。测试不访问正式账本、不进行正式平台导出、不更改浏览器登录授权、不打包或部署。模块测试通过不代表正式浏览器、主机附件桥接或安装包验收完成。
