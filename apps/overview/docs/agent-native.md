# 经营总览 Agent 接口

适配器入口为 `lib/agent-adapter.mjs` 的 `createOverviewAgentAdapter({transport})`。主机传输层注入签名工作台身份、中央复核证明、任务编号和幂等编号；模型输入不能声明身份或审批。独立模块只接受允许列表中的 Agent 路由，原 UI 写接口的限制继续生效。

财务信息、原件、费用和付款操作限老板权限。模板和云仓连接状态可由其他已认证人员读取。付款能力只登记已发生的流水，不执行银行付款。

## 业务覆盖

- 查询：月报、年度/月度看板、账单详情、付款登记、审计、采购/销售来源分类、筛选明细、月报快照。
- 文件：导入模板、月报/运费导出、来源原件、云仓归档文件、已有备份下载。
- 财务复核后执行：新增/更正/作废运费、工资和其他费用；登记/撤销付款；来源分类、覆盖确认、快照留存；原件导入与维护回导；备份恢复到独立副本。
- 云仓：读取连接与下载任务、开始/停止/继续原有下载流程。下载只归档原件，不自动产生费用账单；财务导入另行复核。

所有能力具有中文输入规范，字段、枚举、日期、分金额、分页范围、版本、原件摘要均在服务端校验。列映射通过 `options.mapping` 提供；重新预览后再准备导入。模型只使用 `overview.files.stage({attachmentId})` 接收当前任务附件；可信主机检查任务归属后读取原件，核对元数据，按1MiB分片上传。原件上限50MiB，上传支持跨重启续传、分片及完整SHA256校验。模型不能传入文件路径、字节或摘要。导入预览、导入及恢复副本只接受 `file:{id}`；文件ID绑定当前人员和任务。原有Base64传输仅保留为内部兼容协议，不在公开能力中展示。

## 一致性与回执

准备时使用真实领域校验；事务回滚保证预览不记账。服务端保存私有草稿，公开结果仅含不透明的 preparationId。中央证明绑定人员、任务、能力、结果版本、账本实例、业务与采购/销售来源修订、差异摘要和幂等编号。复核后来源变化会拒绝提交。适配器优先使用主机 transport.binding；主机必须返回 `/agent/binding` 的完整修订（包括采购和销售来源摘要），不能只返回经营总览本地修订计数。

提交前生成完整备份，正式账本与持久回执同一事务提交；重试相同幂等编号只返回原回执。提交后回读领域记录及原件摘要，回读失败则回滚账本事务。回执顶层状态是 completed、pending 或 unknown，后两者不得当作业务完成。备份恢复始终创建独立目录，不替换正在使用的数据库。上传不接受任意本机路径，原件必须提供文件名、完整字节及匹配的 SHA256。

下载结果统一交给可信主机 `transport.download(module,route,{ctx,expectedSha256,filename,maxBytes})`，实际流式保存到中央任务目录并登记任务产物后才返回。适配器替换模块下载URL和ID为中央文件描述，保留下载块类型。缺少下载桥接时明确失败，不返回无法读取的假下载链接。

## 验证边界

测试使用临时真实 SQLite、实际 CSV/XLSX/ZIP 文件、签名 HTTP 请求和模拟云仓浏览器。测试不访问正式账本、不进行正式平台导出、不更改浏览器登录授权、不打包或部署。模块测试通过不代表正式浏览器、主机附件桥接或安装包验收完成。

## 后台任务完成语义（代码待统一测试）

主机适配器按持久任务 ID 查询云仓后台任务，默认最多等待 45 秒，支持 AbortSignal 取消等待；处理未结束、登录/人工接管、暂停、取消、未知提交或回读失败均返回 blocking issue 和真实状态、查询能力及任务 ID。重复启动前先查已有同范围任务，未完成任务不会自动重新启动；完成记录按来源文件 ID、验证标记核对，并通过安全原件能力将产物登记到中央任务。平台返回“已开始”或单独的 completed 字样均不视为产物完成。停止只表示原任务停止，不表示原下载/入账目标完成。后续测试遵循总控代码冻结后的统一执行安排。

## 2026-10-29 最终访问决策（替代旧角色门控说明）

所有真实登录人员均可使用全部业务功能并查看全部业务数据，不再按老板／员工、admin/editor/viewer 或模块成员配置限制业务能力。签名协议中的旧 role/modules/canRunTasks 字段仅保留兼容结构，领域业务不据此授权。销售已登录界面使用统一 member 身份，不再弹出独立老板／员工选择；未签名旧本机接口仍保留原兼容安全边界，不可作为 Agent 身份。

总览归档交接不再要求额外模块授权；仍须真实登录、本任务实际持有的来源产物、runtime 来源标记、人员／任务／SHA 一致。人员目录与销售领域映射只用于归属、防重名和分派，不改变访问权限。真实登录、请求签名、本人身份确认、中央结果页复核、UI确认通道、版本／月锁、幂等、防跨任务原件及Beta维护窗口均保留。没有新增权限管理页面或成员授权接口。

本次访问调整是单独增量提交；新增及更新的测试仅编写，尚未统一执行。不得将旧角色门禁测试的历史通过记录当作新策略验收。
