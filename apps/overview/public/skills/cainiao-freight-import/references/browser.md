# 云仓浏览器操作

这些是已验收过的页面结构；每次以当前页面为准。定位失败后先重新观察，再调整，不循环盲点。

## 查找账单和月份

1. 先发现用户已打开的云仓标签页。已观察到的商家入口为 `https://b.cainiao.com/cf_seller/workbench`。不要为获取登录态另建无关浏览器配置。
2. 「账单管理 → 明细账单」曾位于 `/cf_seller/merchant-counter-bill-manage`。保持时间维度「业务时间」，其余商家、服务产品、费用项和单号筛选清空。
3. 日期输入框的占位符曾为「起始日期」「结束日期」。该控件直接填字符串后可能还原，必须检查实际选中日期。可靠做法是清除旧区间，再通过日历的年、月和日期依次选择开始、结束；选择开始日后日历可能自动切换到原结束日的月份，要重新观察。
4. 日历中 disabled 日期不可绕过。当前月可能只允许截至昨天；最早月份也可能受历史查询窗口限制，不能硬编码为 12 个月或某一固定年份。
5. 点击「查询」后等待实际结果刷新，记录月份、截止日、交易项数、计费金额及币种。结果刷新可能慢于输入变化，不能把上一月的结果用于本月。

## 生成每月官方文件

- 在「交易明细账单」标签点「下载查询结果」。不是「By费用项汇总」标签，也不是付款、结算确认或发票入口。
- 「账单下载配置」中核实「交易账单」「货品信息」「计费明细」均选中，再确定。这只是生成文件，不是确认结算。
- 提交成功后进入「下载任务查询」（曾为 `/cf_seller/bill-detail-downloads-query`）。用任务名称中的起止日期、业务时间、任务状态和任务 ID 对应月份；等待完成再下载。可将每页数量调大，避免漏页。
- 文件可以保存到 Documents 下 `LingtuWorkbench/Imports/warehouse-freight-<本次时间>/originals/YYYY-MM/`；使用唯一批次目录，不覆盖旧批次。保存月度来源清单和 SHA-256，临时签名链接不进入清单。

## 下载事件与弹出链接

按 ego-browser 的 API 文档操作。先在同一轮中监听 `page.waitForEvent('download')`，再点击下载，收到文件后 `saveAs` 到绝对路径。

有的下载按钮使用 `window.open`，原页面收不到 download 事件，弹出页也会立即关闭。此时先检查文件是否已保存，再观察浏览器实际 `Page.windowOpen` 事件；可使用同一浏览器页面的 `page.fetch(观察到的URL, {saveAs: 绝对路径})` 保存文件。只使用刚从该下载操作观察到的官方地址，不猜测接口、拼接签名或输出完整签名链接。

下载原件后才算完成下载，任务状态「已完成」不等于本机已获得文件。不要因为下载失败重复生成同一月份任务。完成后结束本次 TaskSpace，用户原来的标签页保留。
