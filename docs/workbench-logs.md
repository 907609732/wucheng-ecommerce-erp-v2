# 工作台日志与诊断

0.11.2 起，在顶部点击“日志”，或在系统托盘菜单选择“日志与诊断”。

- 选择模块、错误/警告/信息级别，输入关键词后按 Enter 或点击刷新。
- 自动刷新默认关闭，开启后仅在日志页可见时每五秒读取一次。
- “复制当前结果”复制当前筛选内容。“导出诊断报告”导出各模块最近日志与运行状态的 JSON 文件，可自行选择保存位置；不会自动上传。
- “打开日志目录”打开工作台自身日志目录。工作台日志按 4 MiB 滚动，保留当前文件与上一份文件。

工作台记录启动、页面异常、界面进程退出、加载失败、操作失败、更新及连接状态变化。常规状态轮询不反复写入日志。日志带时间、模块和会话编号，失败操作另有请求编号；不记录业务请求参数、响应正文或表单内容。

云仓、采购、销售、总览、导出台和网关读取各自现有日志，没有记录时显示为空，不启动业务服务来制造日志。导出台原日志开关继续有效。客户端只显示本机工作台和私网连接日志，主机业务日志须在主机查看。

常见 Cookie、Bearer、令牌、密码、邮箱、手机号、本机路径与链接参数会被隐藏。旧模块的自由文本仍可能含业务信息，分享前请检查。导出不包含账本、原件、附件、配置、登录分区或认证文件。不能恢复新增日志功能之前未记录的操作。

智能体兼容入口：`云仓库存同步.exe --cli debug-logs --level=error --limit=50 --query=关键词`。`--cli debug-bundle` 返回有界的统一诊断 JSON；旧 MCP 日志工具沿用该适配层。不会通过日志入口开放任意文件、SQL 或 Shell。
