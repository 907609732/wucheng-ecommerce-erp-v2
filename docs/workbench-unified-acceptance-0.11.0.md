## 性能实测范围

同一 Windows 主机各五次新建隔离配置、冷进程启动；不代表冷操作系统缓存，不含业务采集和首次套装解压。旧版首页中位数 1,357 ms，安静环境新版 1,086 ms。并发解压期间另一次新版结果为 1,770 ms，原始记录保留，未用该受干扰批次推断优化效果。空闲五秒观察内，旧版每次五次文件心跳，新版为零；短采样 CPU 均为 0%。未将短采样当成长时间 CPU 保证。

完整离线 Windows Sandbox 另测已加载页面的热切换：采购、销售、总览各返回五次，合计 15 次。中位数分别为 195.29、191.40、206.41 ms；全部样本不超过 219.72 ms，均低于一秒。每个模块保持同一 WebContents 和合成 DOM 输入状态。这些数据仅覆盖已加载内嵌页面的返回，不包含首次服务启动、页面加载或套装初始化，也不代表跨电脑网络延迟。

首屏证据：`dist/module-verification/performance-before-0.11.0.json`、`performance-after-0.11.0.json`、`performance-after-quiet-0.11.0.json`。热切换证据：`dist/module-verification/suite-sandbox-0.11.0/warm-switches.json` 与同目录 `result.json`。

## 安全边界

正式资料目标为当前用户文档目录 `LingtuWorkbench/Data/<模块>`。迁移包含辅助数据库、原件、附件、配置与任务历史；认证分区、DPAPI 和内置 Tailscale 身份保留原物理位置。源数据先私有备份，成功后旧账本封存。开放业务后禁止整库回退覆盖后续编辑。

本机预放行校验发现并准确区分了三处程序性变化：云仓两份内置扩展脚本更新后与同包代码逐字节一致；采购数据集 UUID 与完整身份键集合未变，修订号从 4 增至 5，增量完全由当天启动使用记录解释。校验仅允许这些明确情况，其他业务表、金额及 UUID 仍严格比较，未重置或覆盖身份表。原始差异和复核证据留在私有迁移备份。

CLI/MCP 不提供任意 Shell、SQL、磁盘路径或密钥读取；正式历史订单入账仍要求同一用户在界面完成两次确认。本轮隔离验收不等同于真实平台采集、真实消息发送或另一台电脑已覆盖升级；这些未执行的业务操作不会记为通过。

清理须在真实安装摘要及数据核对通过后才可执行；按明确路径和摘要归档删除，不整删原业务工作区、`tmp` 或 `dist`。正式资料、认证、版本历史、备份和其他独立软件不在清理范围。
