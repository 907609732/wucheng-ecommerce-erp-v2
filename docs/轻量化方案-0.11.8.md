# 轻量化与工程优化：当前决策

更新：2026-11-01。当前事实与验收边界见 [架构](architecture.md)、[开发](development.md)、[验收](verification.md)。原始测量已保存到本轮本地证据目录；历史估算不作为新候选实测结果。

## 已确认方向

- 以五模块轻量业务版为唯一维护主线，保留外部 MCP/CLI 与人工复核。
- 默认轻量安装器，模块与缺失运行时按需下载；不再生产完整离线包。
- 保留预览 appId 与隔离账本；不自动发布或迁移正式数据。
- 先统一架构、构建和验收入口，再按实测优化。

## 本轮处理的卡点

| 卡点 | 修改方向 | 放行证据 |
|---|---|---|
| 构建多条路线、重复 npm ci | Turborepo 按 host 与模块缓存，组装/签名/安装器分开 | 三轮冷/热构建及命中报告 |
| 默认入口被旧管线阻止 | 新统一命令，旧 npm 别名转发，完整离线入口停用 | 命令检查与候选构建 |
| 启动先准备全部模块 | 随包宿主先验证，按打开范围下载和激活；业务适配器懒加载 | 真实模块内容就绪时间，不能只测空外壳 |
| 下载失败需从头开始 | 摘要命名缓存、Range 续传、取消/重试、最终摘要校验 | 故障测试与原版本保留 |
| --prepackaged 裁剪钩子无效 | 在 NSIS 前直接裁剪语言包，打包前后断言 | 仅 zh-CN/en-US，关键资源保留 |
| 每轮验收混成全套 | 快速、集成、发版分层，输入绑定和统一报告 | 缺失证据不得宣称通过 |
| 文档数量多且互相矛盾 | docs 只保留当前 7 类文档，运行记录移到证据目录 | 文档链接检查 |

## 暂不默认采用

- 压缩档 9：原测量显示显著增加打包耗时，默认 1，可独立对比。
- 删除 GPU 回退 DLL：保留低配、远程和禁用 GPU 场景兼容性，需单独矩阵后再决定。
- 压缩或删改 Chromium 许可原文：本轮保留原文。
- 默认依赖系统 Edge：按需浏览器已减少初装负担；替换浏览器仍需真实菜鸟登录、库存、导出链路验证。
- 自动 GC 历史 programs：先确认注册表、活动进程和回滚引用，不能为节省空间误删可用版本。
- Tauri/WebView2、导出模块改内嵌、业务模块重写：不属于本轮工程治理。

## 后续可测量项

根依赖闭包、ASAR sourcemap、导出 renderer 依赖、运行时重复解包、已安装程序身份检查、共享依赖版本差异。必须以最终分发集和真实页面验证为准，不直接套用旧版估算收益。

目标是日常增量构建、快速验收、正常重启同机中位数各降低至少 50%。未达到的项目保留具体测量与原因，不以跳过保护或降低覆盖替代优化。
