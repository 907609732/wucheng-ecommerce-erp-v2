# 经营看板年度默认与可视化验收

## 行为

- 每次打开开发页面默认今年年度看板，不再从旧缓存恢复到月度；页面内可选年/月，业务定向跳转仍尊重指定期间。
- 年度按该年1—12月、月度按该月每日展示，指标、图表、下钻和导出使用同一期间结果。
- 看板待付改为所选年/月所属账单、截至该期间末的待付；旧 `/api/overview` 月报的全部历史余额口径保留。本期实际支付的往期账单仍按付款日期参与本期支出，不把账期和付款日期混用。
- 8项指标、6张图：原收支趋势/支出对比/店铺入账，加累计收支、分类支出走势、店铺与公司收支对比；公司共用费用单列，不自动分摊。
- 新增5类数据覆盖状态，期间明细展开至11列，包含退款、平台费用、采购、运费、人力、其他费用。未知金额为空，退款保留方向，参考差额不称为利润。
- 导出原趋势前5列兼容，追加分类金额，新增累计趋势、归属收支工作表，与页面同源。
