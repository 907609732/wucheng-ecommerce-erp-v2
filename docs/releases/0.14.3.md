# 0.14.3

整合此前已完成的浏览器工作台、工资与付款凭证、业务数据版本托管、NAS 采集修复，以及销售／采购／运费月度对账改造。

- 销售按店铺月份锁定，密码与原因解锁；未录入高亮，支持零收入确认。
- 运费成为独立工作区，按费用来源及实际归属核对与锁定，共用费用不重复分摊。
- 采购录入展示平台月卡，保留表格、手工与历史记录入口，支持零采购确认。
- 统一管理员解锁密码与错误次数限制；旧密码须显式验证后迁移；备份携带一致性密码快照。
- 原销售整月锁优先，数据库同时检查修改前后范围，保留冻结快照和不可变历史。

升级前备份当前唯一正式实例的账本、附件、网关身份、数据版本状态及实际部署配置。NAS 升级保留现有 Compose 的全部挂载、Linux UVCS HOME、网络和采集配置，只更换经验证的不可变镜像。不得启动旧 Windows 正式账本作为新入口。

本版本不包含另行开发中的 OSS／阿里云迁移。当前正式账本仍由已经激活的 NAS 实例提供，基础设施迁移需独立验收与切换。
