# 0.14.4

增加飞牛 fnOS 统一登录入口，继续复用现有 Docker ERP 和唯一正式账本，保留原 Tailscale 备用入口。

- 飞牛应用通过官方统一网关、受控 Unix Socket 和明确 UID 名单验证用户；真实飞牛 UID 与 Tailscale 身份隔离，审计保留具体操作者。
- 采购、销售、运费、经营总览、数据版本及原件链接支持飞牛应用子路径；模块公开前缀绑定签名身份。
- 薄 FPK 只注册入口，不管理 Docker、不创建或迁移账本；停用入口不停止原 ERP。
- 双入口共用业务规则、密码、月锁、备份和托管队列。外网使用明确配置的 FN Connect HTTPS 源，原 Tailscale 校验保持生效。

正式切换必须核对实际 NAS 安装目录、受控 Socket 权限、完整备份和恢复验证；在隔离数据验证身份边界与业务写入，正式账本仅做只读验收。不以局域网成功代替公网中继验收。
