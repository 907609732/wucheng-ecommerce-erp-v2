# 0.13.0 浏览器服务正式包

- 人力支出默认年度工资表，固定1—12月；多人横排录入、加号增人、跨月原子保存、未保存保护；新工资默认月末日期，历史账期和日期保留。
- 新增人力看板，展示年度应付、付款、待付、月度趋势和明细；应付与实际付款口径分离。
- 经营看板默认今年，按选择的年/月隔离统计；8项指标、6张图、完整分类明细、覆盖状态和扩展Excel导出。
- 经营看板待付仅包含所选期间所属账单，按期间末付款计算；旧月报接口保持原历史余额口径。
- 开发版控制台与服务进程树绑定，关闭控制台停止开发服务；正式 WinSW 服务仍独立运行。

本包不包含正式账本、登录资料、主机配置或尚在独立验收的数据UVCS自动托管。后者不作为此版本已交付功能。

安装方式：GitHub Actions 生成浏览器服务ZIP；下载同一运行的ZIP与SHA256清单，验证后解压到独立版本目录，通过现有web:update完成维护备份、复制账本验收、切换及健康检查。失败回退程序版本，不自动回退业务数据。
