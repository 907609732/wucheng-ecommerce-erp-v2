# 0.14.0 数据版本托管

在独立私有 Unity Version Control 数据仓库保存业务历史。每次业务保存固定一份可恢复快照，自动生成中文变更说明并排队提交；软件新增“数据版本”页面，可查询操作人、时间、状态、附件摘要及真实提交号。

网络异常时保留版本等待补交，不重复保存业务。用户会话代理模式在退出 Windows 登录后等待下次代理启动；登录凭据不进入数据仓库。默认保留各模块最近10个已确认本地快照，待提交版本不清理。

保留 0.13.0 年度工资表与看板更新。正式启用与验收状态见 `docs/data-version-acceptance-20261104.md`，维护及隔离恢复见 `docs/data-version-operations.md`。
