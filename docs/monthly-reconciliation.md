# 月度对账与锁定

销售资金对账按店铺和月份核对；运费是顶栏独立入口，按费用来源与归属核对，仍使用销售账本。采购录入按平台展示月度卡片，原表格导入、手工录入与全部导入记录继续保留。

## 使用

1. 首次使用先在销售／运费的“管理解锁密码”或采购管理中设置统一管理员密码。已有旧采购管理员密码时必须先验证旧密码。没有默认密码。
2. 选择月份。没有有效数据的卡片显示“待录入”和暖色边框；部分数据与锁状态分别显示。采购月份以付款日期为准，缺失时回退下单日期，与文件上传时间无关。
3. 打开锁定预览，核对范围、真实金额、笔数及缺项，勾选确认后锁定。无收入、无采购或无费用时可单独零确认，系统只保存核对结论，不造业务记录。
4. 锁定后仍能查看原件和明细；导入、修改、删除、改归属及撤销均受后端约束。解锁必须填写原因并验证统一密码。密码连续错误五次后冷却一分钟，多个业务台共用错误次数。

销售与运费仅能锁定已经结束的月份。采购从次月15日北京时间零点起允许锁定，界面显示具体日期。销售和运费分别锁定；旧销售整月锁优先，解除店铺锁不能解除整月锁。零收入确认保留实际退款和费用，不把有数据的金额强制归零。

自动化／Agent 入口不能直接解锁，须回到真实登录页面验证密码，避免密码进入持久化草稿。修改密码必须先验证当前密码。

## 保存、备份与恢复

工作台通过 `LINGTU_MONTH_ADMIN_DIR` 将采购、销售、运费连接到同一 `month-admin.sqlite`，默认在宿主 `stateDir/month-admin`。`LINGTU_MONTH_ADMIN_LEGACY_PURCHASE_DIR` 指向采购目录，仅用于显式验证旧密码。独立运行时密码库保存在模块自己的数据目录。

完整工作台快照包含 `month-admin/`、三个账本及证据；恢复后须将该目录放回新宿主的 `stateDir/month-admin`，并使用对应模块目录。采购 ZIP 和销售模块备份也包含一致性密码快照；独立恢复时与模块数据库放在同一数据目录。不要只复制账本而遗漏配套密码库，不要把旧密码快照覆盖正在使用的统一密码库。

店铺／费用范围锁及不可变历史纳入销售数据版本白名单；密码库不进入业务数据版本上传。程序升级保留历史锁，隔离升级验收会携带密码库，不写正式账本。

本次为功能分支交付，不执行正式部署或正式月结。上线前应先按现有发布流程备份完整状态，再升级，并由实际经办人员设置或迁移密码。
