# 飞牛 NAS 常驻部署

目标：先用隔离账本在 FN EVO 4 的存储空间 4 验证 Linux 容器、Tailscale Serve、采集、数据版本、备份和重启；全部通过后迁移正式账本并停用旧 Windows 写入口。不得将开发入口转发给成员。

1. 容器：增加锁定 Node 24 依赖的 Linux 构建、Compose 和健康检查。先在 Linux 容器内运行现有合成账本验收，核对采购、销售、总览与附件。程序、账本、状态、Tailscale 状态、备份分别挂载到 SSD 独立目录；镜像更新不覆盖数据。
2. 私有入口：使用独立 Tailscale 容器节点和持久状态，Serve 只代理本机网关。仅允许成员设备访问该节点 HTTPS；不启用 Funnel 或暴露模块端口。验证真实用户身份头及伪造头被拒绝。
3. 采集：将原 Windows DPAPI 与浏览器扩展连接抽象为可替换的授权和浏览器适配器，在 Linux 上实现持久浏览器配置、人工登录和会话失效提示；保持已有固定平台操作及幂等记账。用真实平台账号和实际下载验收。
4. 数据版本：使用 Linux 官方 UVCS 客户端，补齐 Linux 子进程遗留检查；沿用独立私有数据仓库和业务快照白名单。验证提交、失败重试、恢复到新目录。
5. 常驻与切换：配置 Docker 开机启动、容器健康检查及重启策略；从 SSD 备份到另一块盘并恢复演练。NAS 重启和 Windows 双机实测后停写旧服务，最后备份并迁移正式账本、附件、网关状态，核对数据身份和摘要，切换访问规则。保留旧程序与数据供回退，不让双机同时写账。

验收：重启后 HTTPS 登录、三个模块读写、真实采集、数据版本提交、外部备份恢复均通过；平台验证码需要人工重新认证时，采集暂停并提示，不阻断记账查询。
