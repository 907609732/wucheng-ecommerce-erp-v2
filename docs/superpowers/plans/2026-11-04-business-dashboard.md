# 经营看板默认年度与可视化扩展

> Use executing-plans to implement inline; final read-only review.

目标：经营看板每次打开默认今年，年份只显示该年、月份只显示该月，补足数据展示。

复用现有统计、Chart.js、共用周期组件，不增加依赖，不写业务数据，不打包，不切换正式服务。保留工作区已有工资与控制台改动，以及其他任务的文档。

- [x] 测试期间隔离：跨年/跨月记录、所选期间账单的期末待付；旧月报API不改。
- [x] 新增纯可视化投影：累计入账/净支出/参考差额、支出分类时间序列、店铺收支对比；空数据保留null，退款保留方向，合计使用整数分。
- [x] 默认选择今年，页面内选择月/年继续有效；返回经营看板默认年，业务定向跳转仍尊重指定期间。
- [x] 扩展现有看板：8项指标、增加3张图（累计、分类趋势、店铺收支），5类覆盖状态，展开期间明细；全用同一API结果，下钻/导出保持一致，销毁所有图表。
- [x] 相关专项测试、源码开发浏览器验证年/月、无数据、下钻、反复切换及窄屏；独立审查，记录验收并打开开发版。

口径：实付按发生日期，因此本年付款可能来自往年账单；待付按所选期间账单、截至所选期间末计算。参考差额不是利润。支出分类图支持负数净退款，不用饼图制造正占比。
