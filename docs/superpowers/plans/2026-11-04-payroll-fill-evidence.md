# 工资拖动填充、0元及付款图片凭证

复用 Tabulator 6.6.1 的 selectableRangeFill，不重写拖拽工具；复用 Multer 单次付款请求上传图片。只改源码开发版，保留正式0.13.0。

- [x] 工资允许明确0元，空值仍无效；只有工资账单放开0，付款和其他费用保留正数规则。数值0不被转换为空。
- [x] 启用原生填充柄，rangeEdited同步草稿状态，锁定日期/状态/复杂工资与保存中字段；浏览器实测向下填姓名/0元、不更改月份。
- [x] 付款支持最多6张PNG/JPEG/WebP，每张10MB以内；一次multipart请求同时校验和保存付款及图片，失败回滚付款并清理当次原件。原JSON付款兼容。
- [x] 付款记录显示图片、点击查看原件；已撤销记录仍保留凭证。图片预览和移除选择不影响已保存原件。
- [x] 凭证引用写入现有付款payload，不新建表；业务原件放originals，完整备份和恢复必须包含凭证，拒绝路径越界和无效图片。
- [x] 相关单元/API/备份恢复测试、真实开发浏览器拖动和上传验收、独立审查；不打包不自动切换正式版。

开发验收只使用独立合成账本。后续与独立UVCS功能合并时，必须把新的付款原件引用纳入其附件导出白名单，不能只导出付款文字记录。
