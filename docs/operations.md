# 运行与数据维护

当前程序继续使用 `com.wucheng.ecommerce.erp.v2.agentpreview` 和 `%LOCALAPPDATA%/WuchengAgentBeta-preview`，仅开放隔离预览账本。保留外部 MCP/CLI 与人工复核，不提供内置模型执行器。预览模式不能连接正式公司服务。

首次打开模块时下载冻结版本组件；失败时检查网络并重试。取消保留已接收的分片；重试仍验证完整摘要与签名。缺少程序或账本不等于零业务数据，不能显示为可用。日常不使用清空数据来修复程序。

正式历史数据位于用户文档中的 `LingtuWorkbench/Data`；实际使用前仍应核对注册表与程序显示位置。维护前退出对应 ERP 和后台服务，再做带日期的完整备份，并保留外部副本。升级只替换托管程序，不迁移或覆盖正式账本、认证资料。

程序目录、下载缓存、用户配置、账本、附件和备份分开管理。删除旧程序版本前必须核对当前注册表、回滚引用和活动进程；本轮不自动批量清理已有 programs 或用户数据。

排查入口为设置中的日志与诊断；导出日志前检查业务数据范围。CLI/MCP 配置从当前工作台复制，不照抄历史路径或端口。真实登录、采集、发送和业务写入仍遵循现有确认机制。

发布与用户安装存在不同验证边界，见[验收规则](verification.md)。大文件仅使用 GitHub Releases 或用户指定 CDN；未完成发布时保留本地候选，明确标为未发布。
