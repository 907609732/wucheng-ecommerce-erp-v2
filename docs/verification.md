# 浏览器版验收

先运行 `npm.cmd run web:check`、`npm.cmd test` 及三个模块的 `test:purchase`、`test:sales`、`test:overview`。宿主测试覆盖身份、CSRF、重复提交、上传、代理、进程归属、崩溃恢复、版本切换与备份。模块测试覆盖实际业务规则和隔离 SQLite 写入。

`server/release.mjs` 在独立程序目录安装运行依赖，使用合成账本启动三个真实服务，验收成功才标记候选可用。程序目录不含 Electron，不生成安装器。

正式数据迁移必须先核对账本、附件与备份，在副本上比较金额、记录数及恢复结果。源码测试通过不代表真实平台采集或正式账本切换成功。

还需记录真实 Tailscale 双机授权与拒绝访问、查询、记账、导入导出、附件、断网、主机重启及 WinSW 异常恢复。登录、验证码和 Windows 管理员交互由用户完成。未实测的项目须明确列出。
