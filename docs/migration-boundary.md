# V2 迁移边界

## 已迁移

- Windows Electron 桌面端
- 本地菜鸟库存采集和登录流程
- 本地 SQLite 库存与销量数据模型
- 库存发布校验门禁
- 钉钉企业应用机器人发送适配器
- AI CLI、MCP、诊断包和扩展接口
- GitHub Actions 测试、Windows 打包和在线升级

## 明确不迁移

- 旧 Web ERP 和旧服务器进程
- 旧云 ERP 写入、云端同步与服务器部署脚本
- `.env*` 实际配置、数据库、认证状态、日志、报表和下载文件
- 旧项目中的未提交工作区修改

## 后续重做原则

1. 本地优先，业务数据由本机数据库管理。
2. 采集、校验、展示和发送拆成可测试模块。
3. 所有对外写入动作保留确认门禁和审计日志。
4. AI 默认只读；登录、同步、发送和扩展写操作必须显式授权。
5. 新功能只在 V2 仓库开发，旧仓库保持归档状态。
