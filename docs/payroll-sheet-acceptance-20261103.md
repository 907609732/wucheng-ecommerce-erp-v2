# 人力支出在线表格开发版验收

仅源码开发预览：工作区分支 `codex/payroll-sheet`。正式服务保持原版本目录，未创建程序包、未构建/编译版本、未切换正式服务。

## 功能

- 按用户追加要求改为一行多人，共用日期；默认两组姓名、工资金额（应付）、备注、付款状态和明细，右侧加号直接增加人员栏并保留草稿。人员栏数量保存在本机偏好中，不自动新增工资或付款。
- 普通工资批量保存；复杂工资只读展示应发，原代扣、公司承担与付款明细继续由原入口维护。
- 事务、记录版本、请求回执、审计与未保存保护；保存结果不确定时重试同批次，不创建第二批工资。

## 限制
