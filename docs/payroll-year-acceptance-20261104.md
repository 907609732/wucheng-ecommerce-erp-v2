# 人力支出年度表与独立看板验收

## 本轮交付

- 人力支出进入时默认当前年份；只开放年度选择，月份固定在表格左侧，1—12月空月份也可直接填写。
- 保留多人横排与加号；同月需要多笔记录时选择月份并追加行。同人同月旧记录保持独立，不合并金额。
- 人力模块顶栏切换“工资表 / 人力看板”，切换年份、页面均受未保存和提交中保护。
- 年度新工资默认对应月末日期；已有工资保留原账期、日期、ID、版本和原明细。复杂工资继续从原明细入口维护。
- 年度跨月提交使用现有工资API的一次事务与同一幂等回执；不创建付款。不新增依赖、不更换数据库。
- 看板展示年度应付、年度实际净付款、本年度账单当前待付、已录月份、1—12月费用趋势和各月明细。应付包含公司承担，个人代扣不重复相加。实际付款按真实付款/退款日期统计，包含往年账单和已作废账单的有效历史付款。
