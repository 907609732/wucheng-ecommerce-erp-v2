## 原因与修复

相同的 Chromium 程序，使用 AppData 逻辑路径启动时报 `browserType.launch: spawn UNKNOWN`，使用 `fs.realpathSync.native()` 解析后的物理路径可以正常启动。文件有效，错误发生在采集前。

库存同步与登录浏览器统一在启动前解析实际路径；月销量采集复用库存导出入口，同步获得修复。缺失组件明确报错，不自动切换到其他浏览器。独立安装未指定配套浏览器时仍使用原有系统 Chrome 配置。
