# 灵兔启动台使用指南

## 第一次安装

安装工作台后，「每天使用」只展示菜鸟云仓同步；「每月填写」依次展示经营收支总览、销售台、采购台。经营收支总览独立于销售台，放在每月填写的第一个位置。

点击“下载使用”，核对弹窗中的模块、所需组件和下载大小，再开始下载。安装后按钮变成“打开”。运行环境由启动台安装，无须准备源码或执行 npm。

采购台左侧的“历史订单导入”首次使用时下载导出台；首页「每月填写」第一项“经营收支总览”首次使用时独立下载总览，不再从销售台进入。总览缺少采购或销售来源时会显示未接入。

## 已有用户升级

本次本机升级已接回原数据位置。原订单、附件和导出台登录资料继续保存在原处；原独立启动入口仍保留。设置中可以查看模块版本、服务状态和数据位置。

如果提示原数据目录不存在，应先恢复该目录或核对配置，再打开模块。不要把缺失的原账本当成新用户数据重新建立。

## 离线安装

1. 在联网电脑下载 `Lingtu-0.8.0-Complete-Offline-Windows-x64.zip`。
2. 将整个 ZIP 复制到目标电脑并解压。
3. 运行其中的安装器。
4. 打开启动台的“扩展与设置”，导入其中的 `LingtuModules-Complete-Offline.zip`。
5. 选择需要的模块并安装；包内已含全部运行环境。

不要把解压后的业务代码手动覆盖到安装目录。在线与离线安装都会验证官方签名、摘要和版本兼容性。

## 更新和卸载

模块有更新时，核对版本与说明后手动更新。正在采集、导入或保存时，先等待任务结束。安装失败会保留可用版本及诊断信息。

卸载模块只清理托管程序，保留账本和登录数据。以后重新安装可以继续接入原数据。关闭启动台后，已启动后台继续运行；需要停止时在设置中操作。

## 导入历史订单

完成采集后，在导出台点击“导入采购台”。第一次确认逐单核对，第二次确认核对整批数量和金额；正式写账后显示校验结果。账号、退款或采集范围无法确认时，应先补充核实。不要跳过两次界面确认。

安装和测试范围见 [0.8.0 验收报告](./按需扩展验收报告-0.8.0.md)。
