# 运营看板

启动进入功能主页。选择云仓库存同步、运营看板、财务账版或公共设置；右上角返回主页不停止任务，也不清空当前筛选。运营看板沿用原经营数据；财务账版使用独立账本，不从这里复制金额或店铺设置，使用方法见 [财务账版](finance-ledger.md)。

默认打开经营总览，使用一层业务导航：经营总览、销售月报、采购管理、人力费用、邮费与代发、数据核对。销售按店铺拆分表签，截图在金额前面。Excel 来源的销售、采购和人力直接使用可编辑原表，不再分别提供重复的分析明细表；年度采购金额、结余与采购明细在采购管理中切换。采购每月平台支出、月度收支明细、公式栏和人力重复说明区按需展开。

列标题点击排序，标题下方输入框筛选，搜索框搜索本表。月份筛选同时作用于对应业务记录；采购页的年度采购金额与结余、核对和全部凭证不按月截断。原行号与单元格地址保留，销售截图与扣款凭证在相应数据组前显示，人力凭证在金额前显示；排序、筛选均按原行绑定图片，点击缩略图查看原图。只有出现未保存修改时显示保存和撤销按钮。

年度、来源文件、图片凭证数量及经营汇总只在“经营总览”页签显示。默认显示净支付、采购、原表收益、原表结余四项，支付、退款、两种人力费用口径在“支付、退款与人力费用”展开区保留。其他页签直接显示各自内容；导入、导出和错误提示仍在当前页显示。

单机与主服务器支持双击单元格修改，也可选中后在公式栏输入内容，点击“应用”。黄色表示未保存，点击“保存修改”生成新年度版本，旧版本与原文件不覆盖，可通过“历史版本”恢复。保存时重算受修改影响的本工作簿公式，无关原表缓存金额保持原样；不支持的公式、循环引用、缺少被引用公式缓存、数据版本冲突会明确报错并保留草稿。图片不能被文字或数字覆盖；截图内容不会随数字修改而改变，保存后需要对照凭证复核。未保存时暂停年度切换、导入、恢复和导出，避免丢失修改。客户端通过主服务器查看、筛选、排序和导出，编辑在主服务器执行。

顶部“导出 Excel”是统一出口：完整年度表格按原工作表结构导出已保存的数据和对应位置的嵌入图片；选定月份时导出该月份整理后的数据和凭证。单元格编辑记录存入独立 business_edits 表，记录父版本、原值、原公式和新值。

## 导入与更新

在单机或主服务器从右上角“数据管理”选择“导入 Excel”，选择一个年度的原始五表工作簿，或下载标准模板填写。模板、历史版本、原文件下载、全年整理数据导出、全部凭证和刷新均集中在该菜单。先核对年度、记录增减、图片数、收益及差异，再确认保存。空白表示未填报，零表示已填报的零。

同年度导入为完整年度替换，不能只提交几个月以追加；旧版本保留，可在“历史版本”恢复。文件内容哈希相同则不重复导入。导出筛选结果可重新导入，但它只包含筛选范围，不应当覆盖完整年度；如需覆盖，预览会显示被移除的记录数。

标准模板保留记录编号，不根据商品名、人员名或金额自动合并。月份填写 YYYY-MM，金额填数值，百分比填小数（0.05 表示 5%）。模板目前支持三个既有店铺。业务单元格与缓存公式结果分别保存；缺失公式结果会提示，软件不会执行宏、网络公式或外部工作簿引用。

## 口径与图片

经营总览累加月报中的支付、退款、净支付。原表净收益金额与年度结余按原表保留，不作为经审计的利润重算。西施五金的净支付在原表被用作净收益，页面明确保留该口径。共同采购、人力、邮费不按店铺分摊。

人力采用下方日期明细，上方是重复展示和凭证。原表存在汇总重复加 10 元的情况：明细 7384.50 元、原表人力汇总 7394.50 元；原表收益 7913.05 元及结余 518.55 元保留。采购月报、年度汇总、分月小计、逐笔明细分别核对；月报净支付不等于支付减退款时也列出提示。

WPS DISPIMG 图片按图片名称、关系文件和单元格解析，保留所有引用；同一图片文件按 SHA256 去重存储，引用不去重。原始截图不压缩、不做 OCR。缩略图点击可看原图；跨月人力凭证无法明确归属月份时在全年视图保留。

## 导出、存储和客户端

“导出当前筛选”包含选定年、月和店铺的数据及对应图片；“导出全部数据”导出当前年度的完整数据。导出的标准 Excel 包含业务明细、核对说明、来源单元格、原公式文本及图片凭证。图片以常规 Excel 图片嵌入，业务关联保留在图片索引中，不要求重新生成 WPS DISPIMG 公式。“下载原文件”逐字节保存当时导入的原文件。

经营版本、活动年度和图片存入既有 workspace/data/erp.sqlite 的独立 business_* 表；原文件存入 workspace/business。安装与升级沿用原应用数据目录。业务文件不打包、不提交 Git。备份时需要一起备份数据库和 business 原文件目录。

主服务器持有共享数据，客户端通过现有 Cloudflare Access 会话读取、查看原图和导出。导入、恢复只允许主服务器操作；客户端不提供上传端点。远程读取失败时展示错误并隐藏旧内容，不把网络失败显示为无数据。读接口为 GET /api/v1/business、/api/v1/business/images/:id、/api/v1/business/original/:versionId。

## 验证

`npm.cmd run test:business` 使用自动生成的模拟数据验证版本、恢复、过滤与认证。

真实工作簿不放入仓库；在 PowerShell 设置 `$env:BUSINESS_TEST_WORKBOOK` 为工作簿绝对路径，再运行 `npm.cmd run test:business` 和 `npm.cmd run test:business-ui`。UI 验证使用临时数据目录，截图位于被 Git 忽略的 dist/business-verification，不改变正式服务器配置。

## 钉钉 AI 表格

“同步钉钉”读取用户指定的“店铺销售额”AI 表格，使用系统安装并登录的官方开源 dingtalk-workspace-cli。客户端只读取主服务器保存的快照；同步在单机或主服务器进行。无登录、无权限、缺页或凭证失败时不提交该次快照，不清空旧数据。文件和图片仅保存在应用数据目录。

同步保留八张原始数据表、字段顺序、AI 识别文本、公式定义和服务端缓存值。每年建立独立版本，相同内容不新增版本；完整更新保留旧版本供恢复。附件按资源标识缓存，后续同步只下载新增凭证。云端是钉钉来源的编辑入口，软件中可以筛选、排序、搜索、核对和导出，通过“数据管理 → 打开钉钉原表”编辑后再同步；Excel 来源继续支持本地编辑保存。

表格采用单层列标题，店铺分别切换，日期固定在左，截图以同格多附件形式置于数据之前，金额与经营指标使用不同表头底色。邮费、代发和工资保留来源字段；采购页显示钉钉利润表及原表月度采购金额，未提供平台明细时不编造平台分布。钉钉“毛利润、净利润”使用原表口径，未自动扣除原公式未引用的工资、代发或邮费项目。

带图导出含原始字段及快照说明，保留一格多张凭证与字段公式定义，支持重新导入。该格式的表头和图片被改变时拒绝导入，避免凭证错配；普通单元格变更按导出表中的值读取。快照文件允许 500 MB，上限解压 750 MB。系统需安装 dingtalk-workspace-cli 并通过其官方授权登录；不在软件中复制或存储钉钉密钥。
