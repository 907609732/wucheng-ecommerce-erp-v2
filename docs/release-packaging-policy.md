# 发布与打包规范

唯一主线是轻量业务工作台，当前仍保留预览 appId 与数据隔离。默认交付轻量 NSIS 安装器和同一冻结版本的签名组件，停止生产完整离线包。历史安装器保留用于回退。

先运行 `npm run build`、本地验证，再运行 `npm run build:installer`。Turborepo 缓存只复用构建任务；签名、公共载荷扫描、安装器压缩、安装实测与发布核对每次执行。`verify:release` 未通过不能标记为可交付。

组件清单沿用 `lingtu-catalog/v1` 的 Ed25519 签名、主机兼容范围、平台、架构、摘要、大小和依赖。新增 `preview`、`version`、`releaseManifestSha256` 将所有组件绑定当前冻结预览。宿主随包固定目录摘要及完整资源清单摘要，不能从远程替换清单。

首次使用下载模块和所需运行时；归档完成摘要、路径、大小、内容清单校验后才激活。下载到 SHA-256 命名缓存，支持取消和续传，激活失败恢复原注册表。状态报告区分未准备、准备中、可用及失败。

大文件使用 GitHub Releases。发布 tag 带版本与冻结资源摘要，资产名与目录内容必须匹配。未经本次明确发布指令不上传，不自动更新正式通道。新组件 URL 在未发布时不可用，应记录为发布可达性未完成。

压缩默认 1，以构建速度优先；最高档需单独测量。语言包仅保留 zh-CN/en-US；保留图形回退、ICU、ffmpeg 和许可证原文。任何预打包快照重打包后均执行裁剪断言，避免旧快照带回冗余文件。

旧扩展接口及离线套件文档已从当前 docs 删除，历史通过 Git 追溯。签名私钥和登录资料不得进入源码或分发包。
