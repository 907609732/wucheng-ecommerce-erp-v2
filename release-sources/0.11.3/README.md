# 工作台 0.11.3 实际发布源码快照

本目录对应此次实际发布的第一方运行代码，而不是开发工作区中尚未验收的其他改动。

- host：从已安装并已验收的0.11.2主程序冻结，仅修改版本与套件签名目录。
- gateway：原版网关代码，未修改。
- purchase：已验收的采购台1.8.0代码与锁定依赖清单。
- build：实际使用的现有electron-builder配置与打包校验入口。
- scope-proof.json：旧签名目录、新采购包与其余六个组件的保留证明。

完整安装器嵌入全部七个签名组件，无需另行下载业务组件。六个保留组件的ZIP字节及SHA256不变；其实际代码由对应签名ZIP提供。发布页也提供这些ZIP与完整组件清单。

本快照不包含账本、用户配置、登录资料、签名私钥或完整开发依赖树。组件签名使用既有发布密钥；npm生产依赖版本及公开运行环境见随包清单。

采购台回归测试178项通过，生产包解压启动、任务数据、图像依赖和Excel导出通过。完整工作台验收与下载文件摘要另见发布页。
