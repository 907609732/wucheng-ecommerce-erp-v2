    使用说明
    首页直接打开业务功能，程序和运行环境随工作台统一提供。
    经营收支总览位于首页「每月填写」第一项，独立于销售台。采购台左侧可打开历史订单导入。
    在设置中统一检查并安装工作台更新。有采集、导入或保存任务时不能更新或停止服务。关闭工作台后，已启动的后台继续运行。
    点击窗口关闭按钮后工作台留在托盘；从托盘可重新打开或退出，业务后台继续运行。重新安装工作台会继续接入原数据。
    
  
    
    旧账本安全迁移
    将本机业务资料备份并上传到主服务器隔离暂存区。登录资料与密钥留在原电脑。
