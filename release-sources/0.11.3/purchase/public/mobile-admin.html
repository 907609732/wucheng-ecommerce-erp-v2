手机访问

仅通过你的 Tailscale 私有网络连接。先在手机和电脑登录同一账户，并配置设备审批与访问策略。

打开后请查看屏幕右下角托盘；需要登录或连接时在客户端完成。

1. 配置私有地址

在本机终端执行：

tailscale serve --bg http://127.0.0.1:17869

把输出的 HTTPS 地址填到下方。不要使用 Funnel。

2. 扫码配置手机

打开手机相机扫码，在 Safari 或系统浏览器中打开。请先连接 Tailscale。

扫码后自动配对，无需手输配对码。二维码五分钟内有效，仅能使用一次，重新生成会使旧码失效。请勿截图或转发。

备用：手输配对码

无法扫码时使用。生成手输配对码会使二维码失效；配对码也仅能使用一次，请勿转发。
已授权浏览器
每次配对有效三十天，手机丢失时立即撤销浏览器和 Tailscale 设备。
